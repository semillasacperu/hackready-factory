# Fábrica de Proyectos de Innovación Educativa - HackReady

Aplicación web desarrollada como asistente inteligente y generador de propuestas pedagógicas de alta calidad bajo la metodología **HackReady**. Diseñada para respaldar a docentes en la Hackatón de Innovación Educativa (Universidad Científica del Sur & Instituto SISE).

## 🚀 Características Principales
- **Módulo 1: Reto Map** (Clasificación automatizada en los 5 retos oficiales de calidad académica).
- **Módulo 2: Problem Card** (Diagnóstico estricto y auditoría contra soluciones prematuras).
- **Módulo 3: Prompt Card** (Construcción de copilotos de IA estructurados en 7 pasos).
- **Módulo 4: MVP Card** (Diseño de flujos demostrables y rúbricas analíticas breves).
- **Módulo 5: Pitch Card** (Ensamblaje del guion de presentación de 4 minutos y matriz de alineación con guías institucionales GIE-UGD-INS-01).

## 🛠️ Stack Tecnológico
- HTML5 & Tailwind CSS (Diseño responsivo moderno).
- JavaScript ES6+ (Arquitectura modular basada en componentes y servicios).
- Google Gemini API (Integración inteligente de auditoría y generación pedagógica).
